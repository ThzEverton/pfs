# CRUD com Níveis de Acesso

Aplicação de estudo desenvolvida em Node.js para praticar CRUD, banco de dados e diferentes níveis de acesso.

## Funcionalidades

- Cadastro de usuários
- Listagem de usuários
- Edição e exclusão
- Níveis de acesso
- Interface renderizada com EJS
- Persistência em MySQL

## Stack

- Node.js
- Express
- EJS
- MySQL / mysql2
- CSS

## Estrutura

```text
controller/
models/
routes/
views/
public/
utils/
server.js
```

## Executando

Instale as dependências:

```bash
npm install
```

Configure o banco MySQL utilizado pela aplicação e execute o servidor conforme o ambiente do projeto.

## Contexto

Projeto didático para praticar arquitetura básica de aplicações web e controle de acesso. Dependências geradas, arquivos locais e segredos não são versionados.
